# 微信小程序本地试玩

用微信开发者工具打开本目录，选择测试号或填入自己的小程序 AppID。点击首页「成语填字」会直接进入当前关卡。退出后重新进入会继续未提交的关卡，并恢复本机已选字块。

1. 先启动 `java/` 的 `local` profile 后台。
2. 在微信开发者工具的本地设置中，勾选“不校验合法域名、TLS 版本以及 HTTPS 证书”。
3. 编译小程序，从首页进入“成语填字”。当前接口地址为 `http://127.0.0.1:9999/api/local`，只供开发者工具模拟器访问。要改端口时，修改 `config/api.ts`。

提交答案后，前面关卡中尚未答对的题可以在后续关卡再次出现。每关最多放入 1 道错题，仍保留 3 道题和 10 个字块。本地试玩标识存在小程序缓存中，清除缓存后会开始新的试玩记录。

真机和正式环境需要 HTTPS 域名和正式登录鉴权。朗读、排行榜与支付尚未实现。
