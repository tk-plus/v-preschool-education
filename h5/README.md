# 本地成语管理

首次使用时，在 Java 启动环境设置 `ADMIN_PASSWORD`，以 `local` 配置启动后台。初始账号默认是 `admin`，可通过 `ADMIN_USERNAME` 修改。再在本目录运行 `npm install` 和 `npm run dev`，打开终端输出的本机地址登录。第一次成功登录会创建数据库中的超级管理员。之后账号和密码以数据库记录为准。

超级管理员可在「用户与角色」中创建账号、分配角色、启停账号、重置密码，以及创建和编辑自定义角色。自定义角色可获得「查看成语词库」和「预览和发布关卡」权限。账号停用、角色更换或密码重置后，旧会话需要重新登录。

按关键词或难度筛选成语，选满三题后填写关卡名，核对每题的拼音和儿童版释义，并选择挖空字。预览显示关卡序号、免费状态和十个候选字。点击发布会同时保存词条审核结果和新关卡。小程序使用原有流程读取新关卡。

Vite 开发代理默认连接 `127.0.0.1:9999`。这一版仅在本机 `local` 配置开放。会话闲置 30 分钟后需重新登录。

「保存审核」可以单独保存词条的拼音、儿童版释义和难度。「批量生成关卡」默认允许尚未使用的待审核词条生成草稿，也可以选择仅已审核词条。一次最多预览 100 关，可以在预览中审核词条或排除某个词重新组关。整批审核完成后才能发布。预览保存在当前管理员会话中，重新登录后需要重新生成。

「生成儿童版释义」使用 DeepSeek。在本机 `java/config/application-local.yml` 中填写 `idiom-ai.api-key`，以 `local` 配置启动 Java，工作目录设为仓库中的 `java` 目录。接口地址和默认模型在公共配置 `java/src/main/resources/application.yml` 中，也可用本机文件覆盖。点击生成时只发送当前批次中缺释义的成语和词条编号。核对并确认后才写入词库。
