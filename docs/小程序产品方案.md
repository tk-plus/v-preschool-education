# 儿童教育微信小程序产品方案（初稿）

> 本文是讨论稿。购买方式确定为小程序内支付；定价、目标年龄段、权益期限、支付能力准入和排行榜细则仍待确定。

## 一、产品定位

面向家长购买、孩子使用的微信小程序。首页展示多个学习模块，首批考虑唐诗填字、成语填空，后续加入趣味英语单词等模块，并持续扩充。

每个模块可以独立开通，同时提供“全模块权益”。

第一版采用**一个微信账号对应一份学习档案**：购买权益、闯关进度、错题记录和排行榜成绩都归属于该账号，不提供同一账号下的多个孩子档案。家长可使用自己的微信账号购买，孩子在该账号下学习。

## 二、小程序页面

| 页面 | 主要内容 |
| --- | --- |
| 首页 | 模块卡片、适合年龄、练习简介、开通状态 |
| 模块介绍页 | 玩法示例、题目范围、免费体验入口 |
| 答题页 | 出题、提示、提交答案、答案反馈和简短讲解 |
| 模块排行榜 | 展示该模块前十名及当前孩子的成绩和名次 |
| 学习记录 | 已完成题目、正确率、最近练习记录 |
| 我的 | 登录状态、已开通模块、有效期、订单记录、联系客服 |

每个模块先提供少量免费体验题，让家长了解玩法和内容质量。购买与订单入口放在家长侧，孩子练习界面聚焦答题和反馈。学习记录增加已掌握题目、常错题和近期进步。

## 三、权益与收费设计

支持两类权益：

1. **单模块权益**：仅解锁指定模块，例如“唐诗填字”。
2. **全模块权益**：解锁所有普通模块。

建议将“全模块”定义为：**有效期内可使用当前及后续上线的所有普通模块**。如果以后推出成本明显不同的专项课程，再单独定义其权益范围。

权益按期限设计，数据库记录开始时间和结束时间。可选方案包括 30 天、1 年或永久，第一版可以只推出一种期限。具体售价待定。

支持从单模块升级到全模块，已购权益可按购买页明示的规则抵扣；抵扣金额与有效期规则待确定。

进入完整题库时，后台判断用户是否拥有该模块的有效权益，或有效的全模块权益。

## 四、小程序内购买与开通流程

家长在小程序内购买，支付成功后自动开通权益：

1. 家长登录小程序，选择单模块或全模块权益，查看价格、期限及包含内容。
2. 家长确认订单，在小程序内完成支付。
3. 后台核实支付结果后自动开通权益，返回开通状态。
4. 家长可在“我的”查看权益和订单；如支付成功但页面未及时更新，可刷新订单状态。

后台保存订单号、支付状态、权益范围和有效期。支付通知需要验签，开通操作应支持重复通知而不重复发放权益；退款后按退款规则撤销或调整权益。购买、退款和客服信息应对家长清晰展示。

本产品售卖的是数字内容使用权，上线前须按小程序实际主体和服务类目，确认并开通微信适用的**虚拟支付能力**，核实其准入、费率、终端支持及审核要求。不要将普通实物商品支付接口直接用于该权益。

## 五、模块排行榜

每个学习模块设置独立排行榜，展示前十名，并在榜单下显示当前账号的成绩和名次。第一版建议使用**周榜**，每周一按北京时间更新挑战题并重新开始统计，同时保留历史成绩。

排行榜采用每周统一挑战：同一模块的账号面对同一套挑战题，建议每套 10 题，分多屏展示，每屏最多 3 个缺字成语和 10 个共用字块。按答对题数排名，同分再比较完成用时。每周首次完成成绩计入榜单；日常练习不影响排名，可反复练习。成绩由后台根据作答记录计算，不能由小程序直接提交最终分数。

榜单使用家长设置的公开昵称或系统生成的匿名名称，不展示真实姓名、手机号和头像。由家长选择是否参与公开榜单；未参与的账号仍可练习并查看自己的成绩。管理端可处理明显异常成绩和不当昵称。

## 六、管理端功能

| 功能 | 第一版范围 |
| --- | --- |
| 模块管理 | 新增模块、排序、上架、下架 |
| 题库管理 | 新增题目、答案、提示、解析，支持批量导入 |
| 用户管理 | 按用户编号查询用户及练习记录 |
| 商品与权益管理 | 配置单模块及全模块商品、价格、期限，查看和调整权益 |
| 订单管理 | 查询支付与退款状态、处理异常订单 |
| 排行榜管理 | 查看各模块周榜、处理异常成绩和不当昵称 |
| 基础统计 | 用户数、模块使用人数、答题量、订单量 |

新增同类题库应尽量通过管理端完成；出现新的答题交互，例如英语听音选词时，仍可能需要更新小程序代码。

## 七、技术结构

第一版技术栈：微信原生小程序（TypeScript）、Java 21 + Spring Boot 4.1.x 后台接口、Vue 3 + Vite 管理端、MySQL 数据库、Nginx + HTTPS 部署。后台数据访问使用 MyBatis；数据库结构变更使用 Flyway 管理。具体依赖版本在项目初始化时锁定。

```text
微信小程序 ──HTTPS──> 后台接口 ──> MySQL
                           │
网页管理端 ───HTTPS─────────┘
                           │
                    微信虚拟支付能力
```

初版可用一台云服务器部署后台、管理端和 MySQL。题目、用户、答题记录、订单、权益及排行榜成绩分别存储。图片和音频增多后，再考虑对象存储。

若 Java 后台与 MySQL 同机运行，正式环境优先考虑 4 核 4 GB；2 核 2 GB 可用于开发和小规模测试，并需监控内存使用情况。

小程序正式访问后台，需要配置 HTTPS 接口域名及相关备案；不能仅依赖服务器公网 IP。数据库不直接暴露给小程序或公网，权限由后台接口核验。

## 八、第一版范围

- 唐诗填字、成语填空两个模块
- 微信登录
- 免费体验题与完整题库的权限区分
- 单模块权益和全模块权益
- 小程序内下单、支付、自动开通、订单查询及退款处理
- 每个模块独立的前十名周榜与个人名次
- 管理端商品、订单、权益和排行榜管理
- 答题记录和基础统计

英语模块作为下一阶段功能，用来验证新增模块的扩展方式。

### 成语填词模块的首版题量

成语模块以 **1,000 条经过筛选和校对的常用成语**为内容目标，按每关 3 道新题计算，可规划约 334 个普通关卡；实际首发题量和关卡数需结合内容制作进度确定。前 3 关可作为免费体验。关卡由易到难，不另按年龄分组，避免生僻成语仅为增加数量而进入儿童题库。

每个关卡同屏显示 3 个缺字成语，每个成语缺少 1 个字；下方共用 10 个汉字字块。孩子先点成语空位，再点字块填入；填错或想修改时可以撤回并重新选择。10 个字块包含 3 个正确字和 7 个干扰字，由后台生成并校验。若多个成语需要同一个字，字块池应提供相应数量的同字字块，避免无解。

难度主要根据成语常用程度、缺字是否常见、字形相似度、干扰字迷惑性和语义理解要求来划分。前段使用常见成语和容易区分的字块；中段增加相近字与词义提示；后段加入更需要理解语境的题目。拼音和朗读始终可用，提示按既定分级规则提供。具体关卡分段在题库完成后依据试用表现调整。

### 错题复习机制

普通关卡每关安排 3 道新题。到期错题不额外挤入同一屏，可在该关完成后增加一屏复习题；每屏最多 3 个成语，仍使用 10 个共用字块。复习题不计入新成语数量。若当前没有到期错题，就只有一屏 3 道新题。

答错的成语先在本关讲解，再优先安排在后续第 2、5、10 关附近复现；若复习时再次答错，继续安排后续复习。跨不同关卡连续答对 2 次后标记为“已掌握”，但仍保留在个人学习记录中。出题时避免同一道题在相邻关卡反复出现，复习间隔和每关题数可根据测试结果调整。

后台按微信账号保存每道成语的作答、错误次数、下次复习关卡和掌握状态。家长可查看常错成语与已掌握数量。每周排行榜仍使用统一挑战题，不混入个人错题，以保证排名可比。

每完成 10 个普通关卡，开放一个**阶段复习关**，集中复习这一阶段答错或仍未掌握的成语，不引入新题。完成后展示已掌握数量和待巩固数量。阶段复习关不阻塞后续普通关卡，可随时再次练习。

每周挑战另从已校对题库中挑选 10 题，尽量覆盖不同难度。

### 拼音与朗读

成语题目显示拼音，并提供朗读按钮。答题前只显示已给出汉字的拼音，缺字位置不显示答案及拼音；朗读时用“空一格”提示缺字，避免提前念出正确答案。例如“兴高□烈”显示 `xìng gāo ＿ liè`，答题前朗读为“兴高，空一格，烈”。

字块中的汉字可分别标注拼音，帮助孩子识读。答题后显示完整成语及拼音，朗读完整成语，并提供简短释义。例如答案揭晓后显示“兴高采烈”及 `xìng gāo cǎi liè`。

题库需逐条校对多音字读法。朗读音频分为答题前提示和答题后完整成语，不能直接用完整成语音频作为答题前提示。

### 字块、提示与答错反馈

每道题保存经人工校对的正确缺字。每屏的 10 个字块由后台根据本屏题目生成，确保三个空位均有对应字块、干扰字不会组成另一种合理答案；同时校对成语写法、拼音、释义和难度，避免孩子合理作答却被误判。

提示分级提供：第一次提示给简短释义，第二次提示给缺字拼音。使用提示后仍可完成关卡，但学习记录标记提示次数，便于后续复习和判断掌握程度。

答错时温和展示正确答案、完整拼音和一句适合孩子理解的解释，再将该题加入后续关卡的复习队列，不要求孩子反复卡在同一道题上。

## 九、待讨论事项

1. 目标用户的大致识字水平，以及关卡难度分段。
2. 单模块和全模块的售价、有效期。
3. 全模块权益是否覆盖未来所有普通模块。
4. 首批题量、题目来源及内容审核方式。
5. 小程序主体、教育服务类目及虚拟支付能力的准入与审核要求。
6. 排行榜的具体题数、分值、同分规则和家长参与授权方式。
