## 开发和部署注意点

- Java 本地启动启用 `local` profile，默认端口 `9999`。IDEA 中的「有效配置文件」填 `local`。如需读取本机外部配置 `java/config/application-local.yml`，Java 启动的工作目录设为仓库的 `java` 目录。服务器通过环境变量设置 `DB_URL`、`DB_USER` 和 `DB_PASSWORD`。
- 微信开发者工具导入 `miniprogram` 目录。本地模拟器使用 `http://127.0.0.1:9999`，需要在开发者工具的本地设置中关闭合法域名校验。正式部署要配置 HTTPS 域名和正式登录鉴权。
- Flyway 会在后台启动时执行新迁移。已在数据库执行过的迁移应保留原文件，后续变更新增版本。已有答题记录的数据库保留原库并正常升级。
- `docs/idiom.json` 是本地使用的第三方原始数据。词条难度初评主要依据长度和词库内的汉字出现次数。发布前仍需核对拼音、释义和适龄程度，正式版的释义和例句使用授权明确的内容。
- `java/target/` 里的导入和难度 SQL 可以重新生成。恢复开发库时，先启动 Java 应用迁移，再运行 `python scripts/prepare_idiom_import.py` 并在 MySQL 客户端执行生成的导入脚本。完整流程见 [Java 运行说明](../java/README.md)。
- 当前试玩身份保存在小程序本地缓存里，清除缓存会开始新的试玩进度。购买目前只有解锁提示，微信支付、正式登录、排行榜和管理端业务页面仍待实现。

## 提交前检查

- 提交 Java、小程序、H5 源码，Flyway 迁移，Python 导入脚本，项目文档和 `h5/package-lock.json`。
- `java/target/`、日志、`node_modules/` 和本机配置已有 Git 忽略规则。数据库密码留在本机外部配置或环境变量中。
- `docs/idiom.json` 仍在工作区，建议先留在本机。下面的暂存命令会排除该文件。小程序公共配置中有实际 AppID，提交前确认这是打算给团队使用的项目 ID。

```powershell
git add -A -- . ':!docs/idiom.json'
git diff --cached --stat
git status --short
git commit -m "feat: add idiom practice and question bank"
git push origin main
```
