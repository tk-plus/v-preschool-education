# 知芽星球开发总结 · 2026-11-11

## 今天完成

- Java 后台按 `game` 和 `admin` 分包，管理端和小程序使用各自的接口。管理端新增数据库登录、用户启停、角色权限和密码重置。Flyway V10 已在本地 MySQL 执行。
- 管理端采用左侧菜单。「学习模块」下有「成语填字」，「系统管理」下有「用户与角色」。词库支持按难度和关键词分页，并显示当前筛选的总条数。
- 成语填字支持单关编排、词条独立审核、随机批量组关和整批发布。每关 3 题，每批最多 100 关。生成预览后可以排除个别词条，已使用的成语会在后续批量出题时跳过。
- 接入 DeepSeek 生成儿童版释义。生成结果可修改、勾选并批量确认入库。临时网络错误会自动重试，缺释义的词条会集中显示，方便手动填写或替换。
- 已发布关卡面板显示总关数、关卡名称和解锁状态。收工时通过本地 Java 接口核对，**当前开发库有 322 个已发布关卡，最新是第 322 关**。仓库迁移提供最初 11 关，后来发布的关卡保存在本地 MySQL。

## 使用和提交注意点

- IDEA 启动配置使用 `local`，工作目录设为仓库里的 `java`。管理员初始化密码、数据库密码和 DeepSeek 密钥放在 Git 已忽略的 `java/config/application-local.yml`。DeepSeek 密钥使用 `idiom-ai.api-key`，模型和地址默认值由公共配置提供。
- 成语原始数据 `docs/idiom.json`、本机配置、运行日志和 `target` 生成文件留在本地。需要迁移这 322 关时，另行备份和恢复 MySQL 数据。
- 批量预览依赖当前管理员会话，未确认的 AI 释义暂存在页面。刷新页面或重启后台前，先保存已核对的释义。已确认的词条可以在后续组关时复用。
- 当前公共配置的免费关卡上限为 300，可用 `IDIOM_FREE_LEVEL_COUNT` 覆盖。超出上限的关卡显示解锁提示，实际购买尚未接入。
- 词库里的难度是自动初评。生僻或不适龄的词条可能进入入门草稿，发布前要检查词义和适龄程度。
