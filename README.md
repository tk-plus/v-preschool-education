# 知芽星球（暂定名）

儿童学习微信小程序项目。产品名尚未完成微信小程序名称及商标核查。

## 目录

| 目录 | 用途 |
| --- | --- |
| `miniprogram/` | 微信原生小程序源码 |
| `java/` | Java Spring Boot 后台接口；同时服务小程序和管理端 |
| `h5/` | Vue 管理端网页 |
| `docs/` | 产品与数据库设计文档 |

## 文档

- [小程序产品方案](docs/小程序产品方案.md)
- [数据库设计](docs/数据库设计.md)

当前三个代码目录仅有 `.gitkeep` 占位文件。开始开发后，将对应项目源码放入各自目录，再删除占位文件。
